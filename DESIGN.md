# Design System: MerchFlow Tracker

## Overview

An Operate surface: tables, figures and document review for people reconciling tour merchandise. Light theme, white cards on a near-white page, one red accent. Brand shows in precise details, not decoration. Tokens live in `app/globals.css` (`--mf-*` brand values, `--color-*` theme roles) and are exposed to Tailwind as `danger`, `success`, `warn`, `info` and `ai` (each with `-bg` and `-border`).

## Colors

- **Red** (#E8003D): primary buttons, current navigation item, focus ring, links (text links use `--color-red-text`, #C70034, for contrast on the grey page). Never used for a zero or a neutral figure.
- **Danger / success / warn / info**: state only. Text colour on its own `-bg` passes AA. Danger (#B00020) is distinct from brand red and means a problem.
- **AI** (#6B3FA0): content generated by the projection agent.
- Neutrals: text #1D1C1D, secondary #4B5563, muted #6B7280 (only on white or the page background; on #F1F2F4 use secondary).

**The Red Means Something Rule.** Red marks the primary action or a real problem. A zero, an empty list or a missing value is never red.

**The Missing Is Not Zero Rule.** A value absent from its source shows as "Not in settlement", "—" or a labelled gap, never as $0.

## Typography

Inter for everything; Inconsolata only for SKUs, IDs and code. Numbers use tabular figures (`font-variant-numeric: tabular-nums`, on by default in tables). Page titles 28px/600, section titles 18px/600, body 14px, labels 12px/600 sentence case. No letter-spaced uppercase eyebrows above headings.

## Layout

Sidebar (224px, 64px collapsed) is sticky to the viewport; the window scrolls, so table headers can stick to it. Content max width 1600px, gutters 16/24/32px. Sections separate with 32px; items inside a card with 12–16px.

## Elevation & Depth

Flat cards with a 1px border and a faint shadow. No hover lift.

## Components

- Buttons: `components/ui/Button.tsx` (primary red, secondary white with border, ghost, destructive).
- Status badges: `components/ui/Badge.tsx`, semantic variants only.
- Tables: `components/ui/DataTable.tsx`; header sticks to the window from `lg` up.
- Page headings: `components/layout/PageHeader.tsx`.

## Do's and Don'ts

- Do keep every `data-tour` attribute; the guided tour anchors on them.
- Do label missing source data instead of showing zero.
- Don't use Tailwind palette colours (`text-green-400`, `bg-blue-500/10`) or `text-white` on light surfaces; use the tokens.
- Don't edit `components/merch-flow-report/*` or `lib/merch-flow-report/*`; they are synced from MerchFlow Charts.
